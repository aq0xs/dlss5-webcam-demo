## 🛠️ What You Need

Before you start, make sure you have the following:

- **Windows 10 or Windows 11** – This demo only runs on Windows.
- **A webcam** – Built-in laptop cameras or USB webcams both work.
- **Graphics card with DLSS support** – An NVIDIA RTX graphics card is recommended for the full experience.
- **ReShade software** – This is a free tool that helps the demo run properly. You'll need to download it separately.
- **An NR runtime package** – This is additional software that enables the Neural Rendering features. You can find it online from NVIDIA or community sources.

The demo will still open without ReShade or the NR runtime, but you'll only see regular DLSS Super Resolution (which improves image quality). To see the full Neural Rendering effects on skin, hair, and fabric, those two extras are required.

### Step 3: Get the NR Runtime

The NR runtime is a small software package that enables Neural Rendering. You can find it through NVIDIA developer resources or community forums. Download it and save it in an easy-to-find location.

### Step 4: Launch the Demo

Once everything is downloaded:

1. Double-click the demo application file to run it.
2. The demo will automatically detect your webcam during startup.
3. If ReShade and the NR runtime are properly installed, the demo will show the enhanced view alongside your original webcam feed.

### Step 5: Troubleshooting

If something isn't working correctly, try these tips:

- **Webcam not detected?** – Make sure your webcam isn't being used by another application. Close other apps like Zoom or Teams.
- **No NR effects visible?** – Check that ReShade is running and the NR runtime is installed in the correct folder. Restart the demo after installing missing components.
- **Slow performance?** – Close other heavy applications to free up system resources.
- **Black screen?** – Update your graphics drivers to the latest version from NVIDIA's website.
